# ステージ5 — しゃがみジャンプの同時発動

Issue #10 / #9 / #11 に対応。壁とおばけが同位置にあるとき、片方の命令だけでは失敗することを分かりやすく体験できるようにする。

- x=600 に壁とおばけを重ね、ジャンプとしゃがみを同時に入力するとクリア可能。
- x=1000 の独立したおばけ、x=1440 の穴、x=1800 の壁で異なる条件の組合せを検証する。
- 短縮命令は `かべとあなとぶ` と `おばけしゃがむ`。
- ジャンプだけでは最初のおばけに失敗、しゃがむだけでは最初の壁に失敗する。
- `はしる` を加えたケースで746tick→574tickへ短縮できることを固定tickで回帰検証する。
- 参照スコアは T_ref=746, C_ref=14, P_ref=10444。参照値は既知の解法による基準値であって最適性の証明ではない。
- ステージ間の解放順は manifest に従い、既存ステージの参照条件やランキング区分は変更しない。

会場の手動プレイテストでは壁とおばけの重なりが視認できるか、しゃがみジャンプの見た目が判定と一致するかを特に確認する。
