# P1 学習導線・30ステージ・秘密の門 改訂受け入れ（2026-10-25）

対象：Issue #10、#120。PR #150。会場端末の操作・小学生の理解度測定は #12 で別途実施する。

## 変更と旧データ保護

- ステージ8と10の各2枚の門に `breakable` / `vaultable` を明示し、通常のスイッチ解錠、秘密の扉破壊、秘密の強化ジャンプによる跳び越しを公開した。
- 通常ジャンプでは閉じた門を越えられない。通常のスイッチを押して進む学習解法は変更せず、秘密語はヒントや推奨辞典に表示しない。
- 新版 `stage-8` / `stage-10` は `2026-10-25-r4`。旧 `r3`、さらに過去の `r2` / `r1` の公式参照値は保存し、過去ランキングのGETのみ維持する。旧版へのPOSTは拒否する。
- 新版の参考値は従来の非秘密初心者解法を用いる。ステージ8は592tick・30文字、ステージ10は632tick・30文字。採点式およびゲームコアの共通速度・衝突係数は変更しない。
- 新たに追加した各6ケースは破壊・強化ジャンプ・通常ジャンプ失敗・任意目標の未達/全達成・秘密走行をカバーする。Workerの同一ソース再実行と達成率改ざん拒否をテストする。

## 教育・競技面の判断

- 初級1〜7で基本の条件ジャンプ・しゃがむ・回数・コイン・スイッチを学び、8〜10で色と形・時間付き門と別解を試す。11〜20では速度床・崩れる床・風・巡回敵・複合条件を、21〜30では鍵・宝箱・橋・動く足場・時限レーザー・ポータルを組み合わせる。
- 30面すべてに秘密の言葉なしでクリア可能な初心者/学習解法、短縮、高速、総合の登録済みプログラムがある。全30面の固定tick、100回リプレイ、Worker再実行の検証を実施する。
- 秘密の扉を単独で利用するとコイン・見送りを省略してしまい、ステージ8/10の達成倍率は12%。満点狙いには別の言葉を組み合わせて回収する必要がある。秘密攻略は発見の自由度として提供し、秘密を使うこと自体に得点を直接加算しない。
- ステージ8/10は「高速に走って必要な物だけ取る秘密の破壊ルート」が登録済みでは上位になるため、攻略の好みの差と最上位ランキングでの均衡は同義ではない。全30面で最低2種類の補正後Pareto候補が成立することをP1の機械的受入ラインとする。3種類以上の面は9・13・25。さらなるPareto拡張は別途レベルデザイン改善案として評価する。
- 3つのランキングは時間・文字数・総合を独立集計する。全ての公開ステージで2種類以上の補正後非劣解が記録されており、秘密攻略だけを唯一の学習解として強制しない。
