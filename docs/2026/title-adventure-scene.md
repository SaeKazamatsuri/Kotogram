# タイトルシーンのワールド化

## ねらい

Webサイトのヒーロー＋カードの構造をやめ、ことグラムの冒険が始まる1つのゲームシーンとしてタイトルを表示する。ステージ選択のマップと同じ配色・道・山・木・キャラクターを使用する。

## 表示

- 世界背景は CSS の地形・道・空・入口で構成し、画像や外部ライブラリを必須にしない
- 手前のタイトルと「遊ぶ」ボタンは高コントラストの夜色の上に配置
- マウスで「遊ぶ」を押すとステージマップに移動する
- 進行記録があるときは、これまでのクリア数を表示する
- 装飾オブジェクトはアクセシビリティツリーから除外し、ボタンと見出しの意味を保つ
- アニメーションは視覚効果に限定し、端末のモーション削減設定を尊重する

## 確認

- 1366×768 / 390×844 でタイトルと遊ぶボタンを同時に表示
- タイトルが横にはみ出さない
- 学習ステージへの遷移をブラウザで検証
- Nuxt標準の文字描画とNuxt Iconで、外部フォント未読込でも表示
