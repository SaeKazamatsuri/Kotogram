# 障害物の視覚刷新

壁は石積みの明暗と縁、穴は底に向かう暗いグラデーションと端の補強、コインは回転による幅変化と浮遊、スイッチは押下状態、扉は開閉状態と枠、おばけは半透明の波打つ輪郭で描画する。

キャラクターと障害物は同じCanvas 2Dの曲線・図形ベースに統一する。装飾用の位相は `elapsedTicks` に依存し、物理当たり判定の座標、タイミングを変更しない。
旧静止PNG画像の読み込みは撤去し、端末に依存しない描画経路を1本化する。

待機画面ではアニメーション時計の `visualTick` でコインとおばけの微小な浮遊・回転を描画する。ゲームの `elapsedTicks`・衝突判定・登録タイムは更新しない。
