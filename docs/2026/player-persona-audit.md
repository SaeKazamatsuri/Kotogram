# プレイヤーの直感とステージ実装の整合性検証

## ペルソナ

| ペルソナ | 行動 | チェックすること |
|---|---|---|
| ことばたんけん | 見た言葉を組み合わせて書く。色を「と」でつなぐ | 複数色・形・助詞・別名で意図どおりの対象を選択する |
| はやさじっけん | 「はしる」「めっちゃはしる」でタイムを短縮する | 速度によるリスクが説明可能で、攻略可能な別案がある |
| うらわざたんけん | 門を壊す、ジャンプで越える、ゴールを見送る | 隠し操作の対象を見分けられ、リスクと報酬が成立する |
| みためたんけん | 障害物の絵とヒントだけで操作を決める | 同じ見た目なら同じ操作が効き、違う仕様には表示の差がある |
| じゅんばんじっけん | 命令を並び替え、ループと見送りを試す | 常時条件と順次命令の違いが矛盾なく動作する |

## 3ラウンドの自動検証

1. 全30ステージで初心者攻略を実行し、一般的な表記ゆれに書き換えた攻略の結果と時刻が一致することを確認する。
2. 全30ステージで最速攻略・既知の総合攻略を実行し、ゴール到達・所要時間を確認する。
3. 全30ステージの失敗ケースと回帰ケースを2回ずつ再生し、ステータス、所要時間、失敗理由が一致することを確認する。

## 特別シナリオ

- ステージ14：赤と紫を見送り、緑と黄を1行で選んで押す。
- ステージ14：「みどりとあかのぼたんをおす」は赤い危険ボタンも押すため失敗する。
- ステージ14：高速移動と特殊ジャンプで2つの門を突破し、通常ジャンプでは失敗する。
- ステージ19：赤と黄を見送り、緑と青を1行で押してから障害物を突破する。
- ステージ19・28：門の種類による攻略の違いを表示上のマークで識別する。

## 判定の原則

- 隠し攻略をすべての門に一律付与せず、門の能力は視覚的に明示する。
- 入力を複数条件として解釈する際、色と形の組み合わせを勝手に増やさない。
- 単純なクリアだけでなく、失敗理由・経過時間・安全でない操作も検証する。
- ステージ内の任意ボーナスと必須クリア条件を区別する。
