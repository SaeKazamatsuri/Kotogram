# 2026-10-25 P1 全6課題の実装・受け入れ

対象: PR #111。Issue #110、#9、#10。

## 1. 実行コードを追えるようにする

パーサーのASTの位置情報を `SourceMap` に保存し、`GameProgram` は従来どおり `watchers` と `steps` のみを保持する。Game Coreの `stepGame` に省略可能なTraceObserverを渡すと、実際に受け付けた命令のみを `kind / index / tick / action` として通知する。ゲーム判定・公式tick・再実行形式は従来のまま。

実行中はエディターを読み取り専用にし、発火した行を背景色とガターの▶で強調する。条件待ちは淡い色・…、繰り返し中は↻で区別。複数発火も複数行表示できる。初期のフレームでは18tick分だけ直近の発火を見せ、画面描画はRAFにつき最大1回。ガター・本文のオーバーレイは行高とスクロール量を共有する。最適化された単一の繰り返し監視も元の開始行に対応する。

## 2. パーサー

既存の命令の意味を変えずに、自然文の条件表現（みつかったら・みえたとき・ちかづいたら等）、条件の「または／あるいは／や」、丁寧な動作語尾「ね／ください」などを追加。語彙の追加は `/reference` の制御語一覧へも反映される。曖昧な構文のサイレント受理は避け、従来のエラーケースも回帰テストを維持する。

## 3. 隠し動作を攻略上の発見にする

隠しジャンプ・隠し走行は引き続きクリアに必須ではない。秘密の言葉を画面に列挙せず、実際に秘密の行動を使ったときだけクリア結果に「ひみつの近道を 発見！」を表示する。スコア加点はせず、入力したコードによる既存ランキングの公平性を維持する。世界2のstage-18には大小の穴を組み合わせて、通常の走行と強化ジャンプで異なる動き方を考えられる構成を採用。

## 4. 30ステージの難易度

前回の全30ステージ分析で、第2世界のstage-18が約200tickで終わる一方、第2世界には1252tickのステージもあった。stage-18を`goal=2020`、幅130の穴1つと幅80の穴1つに調整し、短すぎる中盤の体験を改訂した。版は`2026-10-25-r2`とし、旧`2026-10-20-r1`をランキング閲覧用に維持する。世界1、3の公開配置と共通物理係数は今回変更しない。

## 5. 繰り返し構文

2回の繰り返しで大小の穴を越える登録済み回帰解法と、1回では失敗する否定解法を設定。stage-8/9/10/14/17/18/19/20/22/27/28/30には繰り返し攻略の任意課題を用意し、達成時に「くりかえし達成！」と表示。初回クリアに繰り返しを強制せず、同じステージを別のコードで攻略する動機にする。

## 6. 最速・最短・総合の価値

従来のタイム・文字数・総合点の採点式は変えない。結果表示で時間に寄せたコード・短いコード・両立を相対的に判定し、攻略の方向性を言葉で示す。`analyze:stages` は全30ステージの登録済み解法についてPareto非劣解集合も出力する。これは既知登録例に限り、数学的に最良とは保証しない。

## 受け入れ試験

- Parser/SourceMapとGameCore Traceの行番号照合、同tick複数発火、逐次ループ、繰り返し最適化
- 新しい自然文と従来のパーサーのエラー・同等性
- ステージ18の初心者/学習/短縮/高速/繰り返し2回成功・1回失敗
- スコア戦略の表示分類と旧r1版の参照保持
- 実ブラウザでの実行中の読み取り専用と行ハイライト
- 全30ステージ固定tickの照合、Workerの再実行・スモーク、静的Nuxt生成

## 公開

旧版ランキングはGETを維持し、新版での投稿のみを許可する。ステージ18の配置を更新するため、**APIを先にデプロイし、その後フロントエンドをデプロイ**する。実機での描画高・入力機器・音量と小学生の初見での学習検証はIssue #12へ残す。
