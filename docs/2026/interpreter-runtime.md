# ハイブリッドInterpreter v1 — 実装仕様

関連: [言語仕様](language-spec.md) / [ゲームエンジン](engine-spec.md) / [Issue #3](https://github.com/SaeKazamatsuri/Kotogram/issues/3)

## 位置づけ

小学生が短いプログラムを書けるようにしつつ、順番のある処理と繰り返しを教えられるよう「継続監視＋逐次実行」のハイブリッド方式を採用する。詳細ルールは実装上の暫定案として、子どもによるプレイテストを受けて変更可能とする。

## トップレベルの条件付きルール

~~~text
かべとぶ
おばけしゃがむ
~~~

- ゲーム開始から終了まで、条件が成立するたびに発火する。
- `かべとぶ` は最初の壁だけでなくすべての壁に反応する。
- `かべとあなとぶ` は壁または穴（OR条件）に反応する。
- `かべ3かいとぶ` は受理に成功したアクションが3回になった時点で停止する。
- 同じルールと障害物IDの組は一度だけ受理する。連続フレームで回数が減り続けない。
- トップレベルの `もし かべが あったら / とぶ / おわり` は `かべとぶ` と等価。

## 逐次命令と複数命令の繰り返し

~~~text
3かいとぶ
~~~

ジャンプを3回順番に受理する。空中やクールダウン中は次のtickで再試行する。

~~~text
3かいくりかえす
かべとぶ
おばけしゃがむ
おわり
~~~

- ブロック内の条件付き命令は「次のまだ使っていない対象を待ち、その動作を実行する」という意味になる。
- この例は「次の壁でジャンプ→次のおばけでしゃがむ」を3セット順に実行する。
- 同じ障害物IDを別の逐次待機で二重に数えない。
- Tabやインデントの深さは解釈に影響しない。`おわり` でブロックを閉じる。
- 入れ子の繰り返しを許容する。Compilerはブロックの命令列を回数分展開せず、ループの開始と終了を持つ。
- ループの次の反復は少なくとも次のゲームtickから開始する。例えば3回のしゃがみが一瞬で全部消費されることを避ける。

### ひとつの条件付きルールだけを繰り返す場合

~~~text
3かいくりかえす
かべとぶ
おわり
~~~

は `かべ3かいとぶ` と等価な回数限定の継続監視となる。省略構文による文字数短縮を可能にする。

## もしの挙動

トップレベルの単一アクションの `もし...おわり` は常時監視。逐次ブロック内の `もし...おわり` は、その位置で条件を満たす未使用の対象が現れるまで待ち、続いて本文を順番に実行する。

トップレベルの複数アクションを含む `もし` は現段階では未対応としてエラー診断する。誤った順序で一部だけ動かすことはしない。

## 内部状態

Parser → AST → Compiler → GameProgram({watchers, steps}) → Game Core

- watchers: 条件が成立するたびに反応する常時監視ルール。各ルールの受理履歴を保持。
- steps: 逐次処理するアクション、条件待機、ループ開始・終了。
- cursor: 現在の命令位置。
- sequenceProgress: 現在の命令で受理された回数。
- sequenceConsumed: 逐次処理が使用した障害物IDの集合。
- loops: 繰り返し回数とブロック位置のスタック。
- 1tickの命令処理に上限を設け、無限ループによるフリーズを避ける。

ゲームの各tickでは継続監視の評価後に逐次処理を進める。ジャンプ要求が重複するときは、実行可能な一回だけを受理する。ジャンプとしゃがむは併用でき、既存のしゃがみジャンプを維持する。

## 回帰テスト

- 同じ種類の複数障害物へ継続反応。
- 複数行の順序付きループ、入れ子ループ、`3かいとぶ`。
- 同じ対象を続く2回の逐次待機に使わない。
- 逐次命令が待機していても常時監視は働く。
- `もし` がトップレベルでは継続監視、ループ内ではイベント待機になる。
- 同じコード・ステージで同じtick数と結果。
- 旧ステージ・しゃがみジャンプの回帰。
- 検知対象のない待機で実行が停止せず、tick上限で終わる。

## レベルデザインで要検証の項目

- 同じ障害物に常時監視と逐次待機が重なったときの直感性。
- イベント待機中に対象が過ぎたときのヒント表示。
- トップレベルの複数アクションを伴う`もし`の将来の意味。
- 将来の速度変更（はしる / あるく）、待機（まつ）の実行順序。

子ども向けの説明文案:
- 「かべとぶ は、かべをみつけるたびに とぶよ」
- 「かべ3かいとぶ は、3かいとんだら おしまい」
- 「くりかえす に2ついじょうかいたら、うえから じゅんばんに うごくよ」
