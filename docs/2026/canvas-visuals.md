# Canvas描画改善（Game Core非依存）

Issue #11 / #10 対応。背景とキャラクターの状態を読み取り専用の GameState から描画し、判定・公式tick・ランキングデータは変更しない。

- ステージ4は夕焼け、ステージ5は薄暮の配色。従来ステージは昼の既定色。
- 描画中の地形の遠景は GameState.px に基づく座標で更新し、物理処理へ戻さない。
- プレイヤーのあるく・はしる・じゃんぷ・しゃがむ・同時動作を画面左上で表示。
- 同座標の壁とおばけは枠線と「2つ!」の表示で識別し、見た目だけで回避が必要な状況を伝える。
- プレイヤー・壁・おばけ・ゴールの画像が見つからない場合は代替描画を維持。
- プレイヤー状態判定は `app/game/visuals.ts` の純粋な関数で計算し、Node単体テストで不変性を検証。

手動検証: 壁とおばけが重なるときの視認性、画像読み込み失敗時の可読性、1280幅以下/高DPI、低FPS、色覚差に依存しない文字案内。
