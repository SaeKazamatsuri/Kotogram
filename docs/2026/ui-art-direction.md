# 2026 ゲームUI アートディレクション

## コンセプト

ひらがなを入力して旅に出る「小さなアドベンチャー」。Web管理画面に見えるナビゲーション・同じカードの反復を捨て、場面ごとの画面構成と操作盤としての統一感を優先する。

## 色とタイポグラフィ

- 夜空 #10152e：タイトル/ステージ選択の背景。文字は #fff7e8。
- クリーム #fff7e8：読み物や入力の紙面。本文は #20223a。
- ミント #81e3bd：進行・クリア・操作可能な要素。
- サン #ffcd77：主ボタン、報酬、選択中。
- コーラル #fa967b：失敗や注意、演出アクセント。
- バイオレット #a9a6ff：シーン間の装飾。
- 丸ゴシック系日本語フォントを端末標準から優先使用。遠隔フォントのロードがなくても会場PCで読める。
- テキスト階層はゲームタイトル/シーン名/目的/補足。小学生が操作する主要ボタンは52px以上を目安にする。

## シーンと導線

タイトル → ステージ選択 → ゲーム実行 → クリア/失敗 → 次のステージ/再挑戦 → ホーム。
装飾はCSSとCanvasで作成し、ゲームコアの決定論に変更を加えない。

## 移行の単位

1. 共通外観とヘッダー撤去
2. タイトルと冒険マップ形式のステージ選択
3. プレイ画面のレイアウトと情報密度
4. 入力装置としてのエディター・ひらがなキーボード
5. Canvas背景・オブジェクト・クリア/失敗画面

既存の実ブラウザE2Eは新しいシーン遷移に合わせて更新する。会場実機で1366×768、1920×1080、マウス、IME、ズーム125%、配色とコントラストを最終確認。
