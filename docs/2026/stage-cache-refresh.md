# 公開ステージのキャッシュ更新

学園祭会場と自宅では再来訪があるため、追加したステージが以前の利用者に表示されない問題を防ぐ。
- ステージ一覧と個別ステージJSONは5分のTTLで再取得する。
- ページ間で使い回される無期限のメモリキャッシュを廃止する。
- 通信障害時にはuseAssetJsonの保存済みJSONを利用するため、前回取得できたステージはオフラインでもプレイ可能。
- コード・ランキングなど利用者ごとのデータはアセットキャッシュに混ぜない。
- ステージ配置・物理仕様・採点参照値を変える場合は別途バージョンを上げてランキングを区分する。TTLはバージョン管理の代用ではない。
- 本番配備後はブラウザで更新前/更新後のステージ一覧、ネット断での既存ステージ継続を確認する。
