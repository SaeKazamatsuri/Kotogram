# すいっちととびら

## ルール

- 「すいっちおす」は近づいた未操作スイッチを一度だけ押し、targetDoorIdの扉を開ける。
- 開いた扉は通過できる。閉じた扉への接触は失敗となり、ひらがなのヒントを表示する。
- スイッチ同士は独立IDを持つ。同じスイッチを再び押しても二重発火しない。
- 「おす」単独はスイッチへ接近するまで手続き命令を待機する。
- 扉とスイッチはステージJSON内の安定IDで紐づく。スキーマは参照不整合・近すぎる配置を拒否する。
- 開閉は決定論GameState内だけで変化し、描画は状態を参照する。
- 再実行でスイッチは未操作、扉は閉状態に戻る。

語彙: すいっち、すいっちおす、すいっち2かいおす。
既存ステージ1〜6の障害物・公式tick・採点基準は変えない。
