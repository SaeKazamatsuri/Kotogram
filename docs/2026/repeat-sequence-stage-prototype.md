# くりかえしが意味を持つ実験ステージ（P1）

## 課題
公開7ステージはすべて継続監視だけでもクリア可能。回数制限や単一条件のくりかえしは `かべ4かいとぶ` で代用でき、複数命令の順序付き繰り返しの使いどころがない。

## 体験
`experiments/stages/repeat-sequence.json` に公開しない試作を追加した。3組の「まちがいスイッチ → コイン → 正しいスイッチ → 扉」を通過し、コインを3枚回収する。
スイッチにオプション `trap: true` を付けると、そのスイッチを押した際に失敗する。事前に見えているまちがいスイッチを押さず、コインを見つけてから適切なスイッチに応答する順序が大切になる。

```text
3かいくりかえす
こいんとる
すいっちおす
おわり
```

- 上記のループは逐次命令として coin → switch を3回実行し、成功する。
- `こいんとる / すいっちおす` をトップレベルで常時監視すると先頭のまちがいスイッチを押し、失敗する。
- `すいっちおす` から始めても失敗する。
- 2回のループでは3番目の扉を開けられない。
- 1回ループを3ブロック並べた長い命令でも成功し、短いループとの文字数比較が可能。

## 再現
`npm run explore:repeat` は loop / expanded / watchers / reverse / short の結果、tick、文字数をJSONで出力して成功条件を検査する。
`npm test` は実験の成功・失敗・既存公開ステージの回帰を検証する。

## 公開前に残す事項
実験配置はプレイ画面のマニフェストには含めず、ランキング版を変更しない。
将来の公開時は正しいスイッチとまちがいスイッチのグラフィックを明瞭に区別し、誤操作を不当な初見殺しにしない設計を追加する。
長い文章での解法とループ解法を比較し、学習目標、ヒント、スコア基準、言語/エンジン/ステージ版とサーバー再検証を同時に更新する。
この実験は学習効果を人間のプレイテストで実証したものではない。

## 2026-10-20 ステージ8再設計（r2）
旧ステージは赤いスイッチを何もせず通り過ぎてもクリア可能だった。新ステージは、スイッチの見送りを条件付きの操作として言語に追加し、3件の危険なスイッチを明示的に見送ることをクリア条件に加えた。

```text
3かいくりかえす
すいっちみおくる
こいんとる
すいっちおす
おわり
```

- 「すいっちをみおくる」「すいっちをおさない」「ぼたんをみすごす」でも同じ操作になる。壁やコインに `みおくる` を使った場合は診断する。
- `みおくる` は対象スイッチを `skipped=true` にし、操作可能な次のスイッチへ進める。同じ対象への `おす` は受理しない。
- 次の `こいんとる` はコインが現れるまで待ち、正しいスイッチに近づいた `すいっちおす` は開閉する扉へ確実に紐づく。
- `requiredSkips=3` により、旧解法 `こいんとる → すいっちおす` を3回実行してもクリアとしない。
- 赤いスイッチを見送った回数をHUDで表示。グレーの矢印マークで見送った操作を描写する。
- 正確な対象の認識と手順を繰り返すことを、トップレベルの継続監視に対する学習目標とする。
- `stageVersion=2026-10-20-r2` と `languageVersion=2026-language-v3` でランキングを分離。旧r1のランキングは読み取り専用として維持する。
- 新版の基準は通常846 tick、30文字、25380 tick×文字。既存7ステージのバランス設定・挙動は維持する。
