# ぼうけんマップ — ステージ選択 UI

## 方針

カード一覧を廃止し、道でつながった7ステージをひとつの世界として表示する。端末サイズに応じて PC は横長、スマートフォンは縦長のマップに切り替える。

- ステージの順番とリンク先は manifest の読み込み結果から取得
- 解放条件は `canPlayStage`、クリア済み判定は `useStats` を再利用
- 「次に遊べるステージ」を優先表示し、そこにキャラクターを配置
- クリア済みはチェック、未解放は鍵と形の違いで識別
- マップは CSS 装飾 + SVG の道 + DOM 操作要素で構成
- 装飾やアニメーションは Game Core、公式 tick、ランキング判定に影響させない
- マウス、タッチ、Tab キーで操作可能。端末の動きを抑える設定に従う
- UI テキストに英語を表示せず、漢字は小学3年生までの読みやすい表記に寄せる

## 主な実装

- `app/pages/stages.vue`：マップ、ステージ入口、現在地、スクロール、状態表示
- `app/stage/world-map.ts`：マップ上の座標と現在ステージの選択
- `tests/world-map.test.mjs`：進行状態と座標のユニットテスト
- `tests/browser/scenes.spec.mjs`：初回表示、解放、リンク、横はみ出し、スクリーンショット

## 確認項目

1. 7ステージが表示され、未解放ステージへは進めない
2. ステージをクリアすると次のステージが現在地になる
3. すべてクリアするとゴールを表示する
4. 「次の人へ」でクリア状態が消え、初めからやり直せる
5. 1366×768 と 390×844 の双方でマップが操作できる
6. モーション削減設定、キーボード操作、通信失敗時の再試行が機能する

## 今後の改善

解放時に旗が立つ演出、マップへの帰還アニメーション、ステージごとの環境音・装飾の追加を段階的に行う。ステージ数が増える場合は座標をステージデータ側へ移すことを検討する。
