# コイン収集のゲームメカニクス

Issue #10 の新規共通ギミック。Parserに存在していた `こいん` / `とる` のプレースホルダーを実際の Game Core に接続する。

- 各コインはゲーム中のみ collected 状態を持ち、再実行でリセットされる。
- プレイヤーがコインに近づき、`こいんとる` の継続監視または `とる` の手続き命令が受理されたとき収集する。
- 受理前のコマンドは回数制限を消費しない。
- `requiredCoins` を指定したステージでは指定数に満たないままゴールした際、失敗理由 `coin` とヒントを返す。未指定の既存ステージは変更しない。
- Canvasは円形コインと収集数を表示し、物理判定を変更しない。
- ステージスキーマではコイン数に対する必須取得数の整合性、IDの重複と位置の重複を検証する。
- 公式ゲームtickは従来の固定60Hzで継続。既存ステージ1〜5の結果とランキング基準は変更しない。

新規コインステージとサーバー側の再現可能なランキング登録は後続PRで追加する。
