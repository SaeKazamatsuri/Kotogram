# 全30ステージ・実測競技比較（2026-10-25・橋とレーザー反映）

## 計測条件

- 対象：時限レーザーPR #143とスイッチ連動橋PR #144を含むゲーム定義、30面
- チェックケース240経路を固定60Hzのゲームエンジンで再実行し、173経路がクリア
- 最速・最短・総合はランキングと同じ比較関数とコイン／見送り達成率補正（completionBp）を使用
- Paretoは達成率で補正したtick・コード文字数の2軸。同一評価座標は1候補とする
- 登録済み解法の比較であり、未登録の全プログラムまで含む数学的最適性の証明ではない
- 再実行：npm run analyze:competition（Markdown）、node --experimental-strip-types scripts/analyze-competition.mjs（JSON）

## 新ギミックによる選択肢

- ステージ22／スイッチ連動橋：最後の門を開けると橋が実体化。通常997tick、最速570tick。旧版の記録は区別して保持
- ステージ24／踏む床：歩く通常729tick、床で減速する高速515tick。減速しなければ門が開かず失敗
- ステージ23／動く足場：最後の穴を3回目のジャンプなしで越える別ルート1442tickを登録
- ステージ29／時限レーザー：通常1047tick、最速597tick。光の消灯を利用するか、しゃがんで避ける

## 残る評価

- 3種類以上のPareto候補が確認されたのは9・13・25のみ。残りは2候補のため、より異なるリスク／リターンを設計する余地がある
- 第2ワールドの最速平均は第1ワールドより短い。経過tickだけを初見難度の尺度にせず、コード修正回数やヒント使用率も追跡する
- 任意達成率12%などの大きな減点が、ユーザーにどう受け取られるかは会場検証を要する
- 鍵と宝箱、二つのゴール、昇降台、ポータルなどは未実装。ルール／得点への影響を整理して別途段階的に導入する
- 本レポートはGitHub CIの決定論的再実行。実機／本番Cloudflareの測定結果ではない
