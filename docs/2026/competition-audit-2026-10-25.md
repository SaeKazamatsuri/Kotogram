# 全30ステージ・競技解法比較（2026-10-25・新ギミック統合版）

## 計測条件

- 対象：PR #141（踏む床 #139 と動く足場の両方を含む）時点の全30公開ステージ
- 登録済み **239件**のテストプログラムを固定tickのゲームコアで実行し、**173件がクリア**
- 使用した採点：Workerと同じランキング補正、未達成目標を `completionBp` で乗算（10000bp = 100%）
- 最速/最短/総合：`app/scoring/score.ts` の `selectBestRuns` および `compareRuns` で抽出
- Pareto：`elapsedTicks / completionBp` と `文字数 / completionBp` の2軸で非支配集合を計測（同一座標は重複除外）
- 使い方：`npm run analyze:competition`（Markdown表示）、`node --experimental-strip-types scripts/analyze-competition.mjs`（JSON）
- 登録済み経路の比較であり、未知の任意コードも含めた**絶対最適解の証明ではない**

## 新ギミックによる具体的な変化

- **ステージ24：踏む床**。歩くルート729tick、踏む床の前で減速する高速ルート515tick。高速で通過すると24tick踏み続けられず、門が開かずに失敗する。変更前の高速372tickより所要時間が伸び、単なる全速走行ではない判断を要求する
- **ステージ23：動く足場**。3つ目の穴をジャンプせず橋で渡る別解を登録し、1442tickでクリア。従来のショートルート1446tickに近いが、文字数の関係で上位Pareto候補は2種類のまま。競技点の面では追加調整余地がある
- 両ギミックとも既存ランキングのstageVersionを変え、過去スコープは読み取り可能なまま分離した

## 評価からの次の課題

1. **選択肢の偏り**：Paretoが3種類以上の面は9・13・25の3面のみ。他の27面は「最速／最短」2軸の典型的な選択肢にとどまる
2. **得点倍率の厳しさ**：ステージ10には12%でクリアする秘密経路がある。成功しても低得点になる設計が子どもの納得感と合うか実機検証が必要
3. **新要素の学習曲線**：踏む床や動く足場のような時間依存の仕掛けについて、初見のヒント閲覧率・成功までの修正回数を観測する
4. **隠れた最適解**：現在の経路数は登録されたテスト解法だけ。探索器や実プレイで未知の速い短い解法を集めて比較を更新する
5. **残ギミック**：鍵・宝箱、橋切替、レーザー、二種ゴール、昇降台、ポータル等は別途設計・検証する

このレポートはCIのゲームエンジン上での結果であり、会場の端末や本番Cloudflareの動作を保証するものではない。
