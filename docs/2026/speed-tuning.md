# 速度制御・初期調整メモ

`はしる` と `あるく` を手続き命令として追加。ステージの `scrollSpeed` を歩行基準速度とし、`はしる` はその1.3倍、`あるく` で基準値へ復帰する。倍率は `GAME.runMultiplier` に集約し、同じ命令を繰り返しても乗算が累積しない。

速度変更は固定tick（60Hz）に影響しない。センサー反応距離は現在速度に応じて再計算されるため、走行中の障害物検知やジャンプタイミングは再試験が必要。速度だけで障害物が回避できるわけではなく、早く衝突するリスクを伴う。

速度コマンドの追加に伴い、ランキングのエンジン識別子を `2026-core-v2` に変更。既存stage-checksのbaselineは未変更で従来解法のtickを保証する。今後、ステージ別の高速解法を追加し、難易度・速度倍率をプレイテストで調整する。初期1.3倍は確定値ではない。
