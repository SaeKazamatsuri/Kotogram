# 共用端末の事故防止

- 旧 `/admin` はページを開くだけで全ステージをクリア扱いにする副作用があったため、閲覧のみの案内画面へ変更。
- ステージ選択の「つぎのひと（きろくを けす）」は、明示確認後にのみ現在端末のアプリ専用キーを削除。
- `kotogram.stats`、`kotogram.bests`、`kotogram.player`、`kotogram.nickname`、旧 `kotogram.ui` 等を削除。他アプリのlocalStorageを消さない。
- 仕様で対象外となった文字サイズ変更UIをレイアウトから撤去。操作時のレイアウトずれを回避する。
- リセットではクラウド登録済みのランキングを削除しない。

確認事項：管理URLへアクセスしてもクリアが増えないこと、リセット確認でキャンセルしても記録が残ること、確定したらステージ解放・自己ベスト・ゲスト識別子が初期化されること。

- クリア済みステージのコードは `sessionStorage` の `kotogram.clearedStageCodes` にステージ別に保存し、同じタブで移動・再読み込みしても復元する。保存されるのは最後にクリアしたコードであり、途中の編集中コードは保存しない。
- 「次の人へ」では、従来のローカル記録に加えて `kotogram.clearedStageCodes` と直近のクリア演出情報を削除する。他サイトのデータやサーバー上のランキングは消さない。
