# 日本語表記と一体感の確認

- 画面ラベルに英語を使わない。英字の見出しや内部開発用の短縮語は表示しない。
- 小学3年生までに学ぶ漢字（書、消、数、字、回、集、開）を使い、難しい字はかな書きにする。
- 説明は最小限にし、ヒントは自分で開いたときだけ見える。
- タイトルからゲームと結果まで同じ暗い背景・同じ操作色とパネル形状を使う。
- Nuxt Icon と Lucide で操作アイコンを統一する。
- Nuxt設定でスタイルの読み込みを明示し、白地に白い文字となる問題を防ぐ。
- Chromiumテストでは背景・英語ラベルの不在・アイコン描画・画面の横はみ出しを確認する。
- 会場実機では文字の読みやすさとマウスだけの操作を確認する。
