# ステージ7 — スイッチで2つの扉を開ける

- 2つのスイッチは別々の扉IDを参照する。「すいっちおす」で継続監視し、近づいたスイッチを両方押す。
- スイッチの押し忘れ・回数制限を1回にした場合は閉じた扉で失敗する。扉を両方開けても最後の壁に対応しないと失敗する。
- 初心者解法、短縮解法、高速解法、代表的な3つの失敗例をステージ検証で扱う。
- 基準値 T_ref=679、C_ref=10、P_ref=6790 は検証解法に基づく。数学的最適値を主張しない。
- サーバーの公式tick再現、ランキング範囲、探索候補に追加。
- 会場では2つのスイッチと対応扉の見分けやすさ、ソフトキーでの命令入力を重点確認する。
