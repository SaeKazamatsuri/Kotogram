# ソフトキーボード

`CommandEditor` の「ひらがなキーボードを ひらく」から表示する。50音表、数字、空白・改行・削除・左右移動、濁点・半濁点・小書きの変換が利用できる。命令の完成パーツではなく文字単位の入力。

ボタンの pointerdown では textarea の選択範囲・フォーカスを維持し、挿入/置換結果を共通の `text` 状態へ反映する。IME変換中はソフト入力を無効化。サニタイズ処理を通すため物理入力と同じ許可文字集合になる。

単体テスト: `tests/soft-keyboard.test.mjs`。UI実機確認では、選択中の置換、濁点を途中へ入れる操作、IME変換中のクリック、低解像度の横スクロールを確認する。

ランキングの名前欄も同じかなキーボードを使用する。画面内のキーで文字・数字・濁点・半濁点・小文字・カーソル移動・削除・空白を操作でき、名前用では改行キーを表示しない。入力欄は読み取り専用かつ inputmode=none とし、スマートフォンのOSキーボードを開かない。最大16文字で、空欄のまま送信した場合はゲスト名になる。
