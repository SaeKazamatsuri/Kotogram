# ステージ内の学習ガイダンス

- ステージヘッダーに数値IDではなくメタデータ上のやさしいタイトルを表示する。
- 各ステージに登録されたlearningObjectives（最大5個）を、コード入力前の画面へ表示する。
- 直接コードを代筆したり命令の完成パーツを選ばせたりしない。あくまで学習目標の説明に限定する。
- ヒントはdetailsを開いたときだけ表示し、自力解決を妨げない。
- 最後のステージをクリアした場合は「つぎへ」ではなく「ステージえらびへ」と表示する。
- 既存のステージ1〜3など、learningObjectivesを持たない場合には汎用説明にフォールバックする。

会場では1366x768と1920x1080でガイドとゲームの表示を確認する。
