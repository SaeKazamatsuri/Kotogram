# P3「魔法の鏡」決定論的な戻り道ギミック（2026-10-26）

関連: Issue #160、PR #161。まず非公開実験ステージで導入し、公開30面にはこのPRで変更を加えない。

## 体験

鏡を発動する自然言語は `かがみにうつる`。初めは右へ自動移動する。
右の鏡で一度だけ左へ向きを変え、戻り道で現れるコインを回収し、左の鏡で再び右へ進んでゴールに到達する。
`かがみにうつる` と `こいんとる` は一度ずつの行ではなく、対象が近づいたときに発火する監視命令として機能する。

鏡を使わずに早くゴールすることもできる。鏡とコインを使うと時間・文字数は増えるが、任意目標の達成率が上がる。採点に使う達成率はWorkerがソースを再実行して算出し、利用者が自由に入力できない。

## データと実装上の境界

- `mirror`: `id`、`position`、`fromDirection`（左右）。2つ一組のopt-in。左の鏡は`left`から接近、右の鏡は`right`から接近した場合だけ発動する。利用済み鏡はもう発動しない。
- `coin.revealAfterMirrorId`: 右の鏡IDを指定したコインは、それが一度使われるまで検知・拾得・描画されない。
- 鏡のペアは320〜1200の距離を空け、手前のアプローチと後続ゴールまでの距離を確保する。途中には通常の壁・穴・風・レーザー・スイッチ等を設置しない。一方向の障害物判定を安易に逆用しない安全な通路制約。
- 鏡を置いていないステージは`direction=1`固定。既存の移動速度、座標、衝突、公開ステージの固定tickを変更しない。
- 逆走中は鏡とコインだけを方向に応じて検知できる。反転のたびに鏡の発火状態と収集状態がゲームコアに保存され、同じtick列で同じ動作をする。
- キャラクターの向き、画面上部の「← もどる」表示、鏡の「← / → / ○」と日本語「かがみ」で方向と使用状態を判別できる。
- おすすめ辞書に鏡の語を出すのは鏡のあるステージだけ。自然言語自体はゲーム共通の辞書へ追加する。

## 受け入れ

`experiments/stages/mirror-return-route.json` を使うテストで、通常の最短クリア／右・左の反転／戻りながらだけ拾えるコイン／反射しないでコインが消える状態／旧ステージ1の712tick／100回繰り返しの一致／偽造tick・達成率の拒否／危険なstage定義の拒否を確認する。

公開への採用時には該当stageVersion、最新スコア基準と旧ランキング参照、公式最速/最短/総合の別解、Workerのリプレイを同時に更新する。本番デプロイは行わず、実機・児童の初見検証は保留中のIssue #12とする。
