# 自然言語によるギミック拡張・ステージ辞典設計

更新: 2026-10-25

## 基本方針

- 全ゲーム共通の言語辞書が唯一の解釈源。表示する辞典はステージ固有の「おすすめ語」の投影にすぎず、掲載外の言葉も全ステージで実行できる。
- 小学生の初見は、各ステージで覚える中心操作を1〜2個に制限。熟練者には全語彙・秘密の言葉・条件の組み合わせを許す。
- 同じ条件は色と形のどちらでも指定できる。色だけの識別を必須にしない。赤/緑の点灯のみで状態判定せず、記号、輪郭、アニメーション、効果音で区別する。
- 「あかいぼたん」「ばつのぼたん」「あかいばつのぼたん」は同じ赤×のスイッチを選択できる。色と図形の複合はAND、複数対象の「と」「または」はOR。
- 条件に該当する対象だけを前方から探索し、操作対象のIDをInterpreterからCoreまで引き継ぐ。条件が違うスイッチを勝手に押さない。
- ゲーム判定の時刻は固定60HzのelapsedTicks。描画FPS、音、雲、アニメーションと無関係。毎回同じ入力なら同じ結果とtick。
- 未達成でもクリア可となる任意目標と得点倍率は #119、閉じた扉の秘密突破は #120 の管理下に置く。Core、採点、Worker再実行、ランキングスコープを一体変更する。

## 色・図形条件の第1段階

| 属性 | 内部値 | 言葉の例 | 図形 |
| --- | --- | --- | --- |
| 赤 | red | あかいぼたん | 任意 |
| 緑 | green | みどりのすいっち | 任意 |
| 青 | blue | あおいぼたん | 任意 |
| 黄 | yellow | きいろいぼたん | 任意 |
| 紫 | purple | むらさきのぼたん | 任意 |
| 丸 | circle | まるのぼたん | ○ |
| バツ | cross | ばつのぼたん | × |
| 三角 | triangle | さんかくのぼたん | △ |
| 四角 | square | しかくのぼたん | □ |
| 星 | star | ほしのぼたん | ☆ |

旧ステージのスイッチは罠=赤×、通常=緑○とみなす後方互換デフォルトを用いる。明示した色・形と罠かどうかは独立した属性であり、「赤は必ず危険」と固定しない。通常プレイでは色と形の両方の図柄を常時表示。配色を除いても形だけで判別できること。

具体例:

```text
あかいぼたんをみおくる
みどりのすいっちをおす
```

```text
ばつのぼたんをみおくる
まるのぼたんをおす
```

```text
もしあおいさんかくのぼたんがあったら
おす
おわり
```

## ステージ別のおすすめ辞典

1. ステージJSON内のobjectsの種類から、条件語（壁/穴/おばけ/コイン/スイッチ/前）と行動語（ジャンプ/しゃがむ/取る/押す/見送る）を導出する。表示は代表表記1件のみ。
2. スイッチがある場合だけ、そのステージ内に実際に登場する色・形の表記例を表示。見た目の種類がないステージに色指定は提示しない。
3. 特定のステージでは `meta.dictionary.conditions/actions/examples` で導出結果を明示的に上書きできる。入門ステージは最小限に、応用ステージでは複数指定の例を選ぶ。
4. `はしる`、`めっちゃはしる`、`すごいじゃんぷ`、`とびら` および今後の秘密語はおすすめ辞典から除外（ユーザーが入力した場合はエンジン側で認識）。全語彙の詳細はゲーム外の開発用 `/reference` で扱う。
5. エディター検査とWorkerの再実行は常に共通辞書全体で行い、表示中の語彙に解釈を依存させない。日本語の助詞・接続語は全ステージ共通。

## 新ギミック候補と具体的な動作契約

| ギミック | 想定する自然言語 | 状態・判定 | 攻略上の選択 | 優先 |
| --- | --- | --- | --- | --- |
| 色・形スイッチ | あかいぼたんおす / ばつのぼたんみおくる | 色・図形・罠・対象扉IDでセンサーを絞る | 正確な条件選択 vs 汎用操作 | P0 |
| 時限扉 | まるのぼたんおす / いそいではしる | 押してからN tick開き、時間切れで閉じる。残りは視覚ゲージ | 近道か安全な遠回りか | P1 |
| 踏む床 | しかくのゆかをふむ | 接地しているN tickで起動。空中通過は発火しない | 速度と接地の両立 | P1 |
| 動く足場 | あしばにのる / あしばがきたらとぶ | 周期T、位相0の決定論的な移動。高DPIでも判定不変 | 乗って渡る vs 強化ジャンプ | P1 |
| 風 | かぜがつよければあるく / かぜをまつ | 区間に一定の加速度を加える。矢印・風車で向きを示す | ジャンプ時刻と速度切替 | P1 |
| ベルト床 | うごくゆかならあるく | 立っている間のみ固定倍率で水平移動 | 走ると速すぎる危険を創出 | P1 |
| こわれる床 | もろいゆかをみたらとぶ | 乗ってN tick後に穴へ変わる、状態永続 | ゆっくりだと落下、素早く脱出 | P1 |
| 順番ロック | あかいぼたんをおしてからあおいぼたんをおす | ID列の進捗で解錠、順序違いでリセットまたは減点 | 並び替え・繰り返し・条件分岐 | P1 |
| 巡回するおばけ | おばけがきたらしゃがむ | 一定区間を周期的に移動し固定tickで位置が決まる | 待つ・しゃがむ・ジャンプ | P1 |
| 鍵と宝箱 | かぎをひろう / たからばこをあける | 色/形タグ一致の鍵1個を消費。鍵の種類も可視形状 | 必須ではない宝箱を開けるか | P2 |
| 橋の切替 | あおいぼたんをおす / はしをわたる | スイッチで橋の実体/非実体を切替 | 行けるルートが変わる | P2 |
| 動くレーザー | ひかりがきたらしゃがむ | 周期Tで照射。床/天井/中央を形と警告線で表示 | 回避のタイミング | P2 |
| 2つのゴール | みじかいみちへいく / たからのゴールをえらぶ | ゴールに付く得点倍率/経過tickで条件分岐 | 速さ・文字数・達成点の三すくみ | P2 |
| のぼりおり台 | だいにのる / うえについたらとぶ | 台が上下に周期移動、上端と移動衝突を考慮 | 遠回りより縦のルートを選択 | P2 |
| まほうのかがみ | かがみにふれたらむきをかえる | 接触時に世界の左右方向を一定区間反転、入力は反転しない | 言語の視点を切り替える | P3 |
| ポータル | あおいもんへはいる | ペアID間で1回だけ位置移動。移動時の時間と制限を明示 | 大きな短縮 vs 任意収集不可 | P3 |

P1以降は新しいGameState・センサー・行動・描画・ステージJSONスキーマを順番に実装する構想。ギミックの名前を増やすだけで終わらせず、自然言語の条件として記述でき、成功例と誤操作例が両方存在することを採用条件とする。

## 受け入れ・検証の優先度

- 同一ソース・ステージ・tickで100回決定論的に同じ結果。0/30/60/120 FPSとタブ復帰でも公式tick一致。
- 色を取り除いたスクリーンショットでも丸/バツ/三角/四角/星、ロック状態、危険が判別できること。危険対象に色のみの手掛かりは禁止。
- 対象ID・色・形の三重指定でも違うスイッチの誤作動がない。OR条件と条件ANDの優先順位をテスト。
- 辞典表示だけがステージに応じて変化し、同一ソースは全ステージで同一ASTとなること。
- 旧言語版のランキングGETを維持、新言語版のみPOST可能。履歴と新記録を混ぜない。
- 各ギミックに初心者向けの非秘密クリア、失敗例、速度/文字数/総合の別解、想定外の短縮チェックを持たせる。
