# P2 秘密の扉ルート・リスクと競技の均衡（2026-10-25）

関連: Issue #151 / PR #159。

## 背景

ステージ8・10の秘密「とびらをやぶる」「とびらめっちゃとぶ」は、スイッチ開放ルートを短いコードで置き換え、得点を奪う傾向があった。一方で隠し命令の発見の楽しみは保つため、秘密語の物理性能は下げず、両ステージだけ攻略時のリスクを得点に反映する。

## 固定小数点の倍率

ステージJSONの任意フィールド `secretDoorRiskBp` に8300を設定した。ゲーム内で、破壊または強化ジャンプで抜けた各扉に83%の達成倍率を掛ける。

- 通常のスイッチ解錠：10000bp（100%）。他の任意目標の達成率を含め、従来と同じ。
- 1枚を秘密攻略：8300bp（83%）。
- 2枚を秘密攻略：6889bp（68.89%）。
- コイン・罠見送りなどの任意目標を達成しないときは、現行の補正に掛け合わせる。1200bpの安全な下限は維持。
- 秘密の破壊と強化ジャンプは同じペナルティ。無関係の通常ジャンプ、速度変更、スイッチ解錠、ステージ9等にペナルティを付けない。
- ランキングに送る達成率は信頼しない。Workerが同一のGame Coreを再実行し、開いた/壊した/跳び越えた扉を数えて確定する。偽装した達成率・tickは拒否する。

## 公開スコープと教育導線

- stage-8、stage-10のステージ版を `2026-10-25-r5` とする。旧版 `r4` / `r3` のランキング基準・閲覧は保持するが旧版へのPOSTを拒否する。
- 基準スコアは通常の初心者解法を据え置き、ステージ8＝592tick・30文字、ステージ10＝632tick・30文字。
- ステージ別推奨辞書では秘密語を明かさない。発見した人は使用できる。
- クリア画面で秘密使用による倍率と任意目標を含んだ最終倍率を日本語で表示する。色だけの表示には依存しない。
- 得点設計の意図は、通常の正確なスイッチ攻略でタイム部門、秘密の短縮コードで総合部門を目指すこと。意図どおりかはGame Coreの実測で確認する。
