# ステージ4 — 回数制限と速度のトレードオフ

Issue #10 / #9 向けの追加ステージ。ステージ1〜3と同じ物理モデル・既存ギミックだけで構成する。

- 壁4つ、おばけ1体。障害物間隔は360〜380pxで固定し、ジャンプ着地としゃがみの猶予を確保する。
- `かべ4かいとぶ` は4回の成功後に停止する。3回指定では最後の壁で失敗する。
- `かべとぶ` は継続監視なので4つの壁すべてへ反応し、より短い解法になる。
- `はしる` では初期歩行3.0px/tickから3.9px/tickとなり、クリアまで806tick→620tickを想定。最終確定はCIと実機テストによる。
- ステージJSONには学習目標と安定した障害物IDを付与した。
- 参照スコアは T_ref=806, C_ref=11, P_ref=8866 を独立管理（理論最適値ではなく公開時の基準）。
- Manifestのバージョンは既存のランキング・スコープとスコア基準との互換性を保つため変更しない。既存ステージの内容と計算式は変更しない。

`npm run validate:stages -- --stage stage-4` と `npm test` で確認する。低FPS、連続再挑戦、反応距離の体感、実機での高速解法の難易度は手動プレイテストで再調整する。
