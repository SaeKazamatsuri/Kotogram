# ゲームCanvasとリザルトのビジュアル更新

- データ依存しない背景描画: sky gradient、昼/夕焼け/薄暮の月・星、遅い雲、2層の丘、木、草の地面と石模様。
- 背景の横移動は elapsedTick ではなく game.px に応じたパララックス。物理・当たり判定・公式tickに介入しない。
- 圧縮や描画負荷を避けるためCSS/Canvasで景色を描き、オンライン画像アセットを追加しない。
- コイン/スイッチ/扉/壁/おばけ/穴とキャラクターのGameState由来の描画は引き続き同じ配列を参照。
- クリア時に3スコアと1000点超過表示、自己ベスト・ゲスト登録、3ランキング・次へを保持。
- 失敗時のヒントと再挑戦導線を統一。モーダルはrole=dialogとaria-modalを指定。
- ローカルChromium自動テストと会場実機にて、1366×768/1920×1080、倍率125%、ゲームクリア・失敗・オンライン順位確認を推奨。
