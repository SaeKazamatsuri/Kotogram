# ステージ6 — コインを2枚あつめる

Issue #10 のギミック学習コース。
- ステージ内には2枚のコインと1つの壁がある。コインは条件付きの `こいんとる` と自動監視で収集する。
- コインを1つでも取り損ねたままゴールすると失敗理由 coin を表示し、修正のヒントを案内。
- `こいんとる` 単独では壁で失敗するため、ジャンプとの併用が必要。
- 初心者/短縮/高速の解法と2つの失敗解法を回帰テストに登録。
- 公開基準は T_ref=512tick、C_ref=9文字、P_ref=4608tick×文字。既知解法に基づく基準値で数学的最適ではない。
- 速度は旧ステージの決定論を変更せず、正式なスコアの基準バージョンを維持。
- 新しいステージ追加でサーバー検証対象が欠けることを防ぐため、manifestの順序とWorker側ステージの一致をテスト。

マージ前の会場確認ではコインと障害物の判別、回収猶予、ソフトキーボードによる `こいんとる` 入力、オンライン登録を確認する。
