# ステージ9〜30と隠しアクション

公開済みステージ1〜8の配置JSONは変更しない。ステージ9〜30は独立した `2026-10-20-r1` として追加する。

## 新アクションと別解

- `すごいじゃんぷ`、`すごいとぶ`: 初速-16の長距離ジャンプ。標準ジャンプ初速-12.2は変更しない。壁2個を1回で越える場面がある。
- `めっちゃはしる`、`すごくはしる`: 通常速度1.75倍で走る。通常の `はしる` (1.3倍) と区別し、`あるく` で解除できる。
- `すいっちみおくる` のほか、`すいっちじゃんぷ` でスイッチ上を空中通過すると、危険スイッチを見送った数に加算される。徒歩で通りすぎるだけではカウントしない。安全なスイッチは引き続き押して扉を開ける必要がある。

## 検証とスコア

- 各追加ステージに初心者・短縮・加速・失敗・回避代替ケースを登録し、再実行による決定論を検査する。
- 初期スコア参照は初心者の通常歩行時tickと文字数。これは理論最適値ではなく、検証済み基準である。
- API Workerの再実行対象にも30ステージを登録する。公開時はAPIを先にデプロイしてからフロントエンドを更新する。
- コマンドはやり込み要素としてUIにすべて列挙せず、プレイヤーの発見を残す。ステージ8の公開JSONは他セッションの調整対象のため変更しない。
