# Issue #11：世界の造形差を作る描画改修

更新日：2026-10-25

## 目的

単なるパレット切り替えではなく、世界を移動したときに輪郭と素材で違いが伝わるようにする。全30ステージのゲームの基本動作、コマンド、ランキングには触れない。

## 3世界の造形規約

| 項目 | こもれびの森（1〜10） | 夕やけの谷（11〜20） | 星あかりの国（21〜30） |
| --- | --- | --- | --- |
| 遠景 | 広がった森の樹冠 | 段状のメサ・地層 | 結晶状の山並み |
| 近景 | 重なった樹木・柔らかな丘 | 岩棚・サボテン | 発光する結晶群 |
| 道 | 黄色い土と途切れた足跡 | 砂色の道と岩の縁 | 青白く光る道 |
| ステージ台座 | 木製の看板・琥珀色 | 砂岩／素焼き色 | クリスタル色・金属縁 |
| 目的地 | 大樹 | 岩山 | 城 |

画面構成、ステージ名、解放可否、番号とフォーカス表示は共通のまま。ステージ5・10には装飾的な星を添え、進行の区切りを作る。

## 描画の分離

- `ScenePalette.biome` は背景美術の形状識別子であり、`day/sunset/twilight` の色のバリエーションと対応する。
- `app/game/renderer.ts` の景色だけが `biome` を参照する。GameState・物理の値・判定領域は変更しない。
- 明るい景色を増やしてもコマンド中のプレイヤーや障害物の視認性を下げない。Canvasの背景美術は障害物の後ろに描く。
- 静的なマップ装飾はCSS。背景画像のネットワーク読み込みを増やさない。
- `prefers-reduced-motion` 時は既存のキャラクター・地点アニメーション停止仕様を維持。雲には追加アニメーションを付けずドラッグ時のちらつきを増やさない。

## 検証

- `npm test`、`npm run typecheck`、`npm run lint`、`npm run test:browser`、`npm run test:visual`。
- 各世界のPC・スマホ表示、最初／最後の地点、マップのドラッグ、世界切替、解放状態、Canvasの背景と障害物のコントラストを比較する。
- 低性能端末のFPS、会場の色再現は未評価。画面を比較して見え方を調整する余地を残す。
